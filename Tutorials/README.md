# 教程

houttuynia-blog 的模块说明。架构口径以仓库根目录 [PROJECT_STATE.md](../PROJECT_STATE.md) 为准，版本 `0.1.0`。这里不引入第二套框架、数据库或存储方案。

第一版代码已经在仓库里。每篇仍写模块职责、相关的表、第一版做不做，并走通一条主流程。

## 阅读顺序

1. [总体架构](architecture.md)：进程、技术选型和一次读者访问。
2. [RBAC](rbac.md)：用户、角色、权限码、会话、菜单。
3. [内容](content.md)：文章、分类、标签、搜索和归档。
4. [存储](storage.md)：上传凭证、七牛直传、公开 CDN 与私有签名 URL。
5. [身份与三方登录](identity.md)：密码登录，以及先不挂路由的微信、QQ、钉钉、飞书。
6. [预留模块](reserved.md)：评论、友链、统计、个人简介、站内 TypeScript 小工具。

## 和第一版的关系

第一版要做的是读者页、后台内容与站点设置、图片上传，以及完整 RBAC（只种子一名 super_admin）。

评论、友链、统计、简介编辑、三方登录页面和小工具只留表、权限码、包或接口。边界的三段（现在做、现在只预留、明确不做）写在 PROJECT_STATE 里。
